# Valuer Bank Selection - Quick Start Guide

## 🚀 Quick Start (5 Minutes)

### For Valuers

#### Step 1: Access Bank Selection
1. Log in to your valuer account
2. Go to Valuer Profile
3. Click **"➕ Create New Report"** button

#### Step 2: Select a Bank
1. Use the search bar to find a bank (e.g., "AU Small")
2. Or click a category filter (Banks, Finance, Housing)
3. Click on any bank card to open the form

#### Step 3: Create Report
1. Fill out the form fields
2. Upload required documents
3. Click **"Save Draft"** to save progress (AU Small Finance)
4. Or click **"Submit"** when complete

#### Step 4: Manage Drafts
1. Return to Valuer Profile
2. Click **"Show AU Small Finance Drafts"**
3. Click **"Continue Editing"** to resume work
4. Or click **"Delete"** to remove draft

## 📋 Key Features

### Search & Filter
- **Search**: Type bank name in search box
- **Clear**: Click ✕ to clear search
- **Filter**: Click category buttons to filter
- **Stats**: See total banks and draft counts

### Bank Cards
- **Icon**: Visual identifier for bank type
- **Name**: Full bank name
- **Category**: Bank type (Bank/Finance/Housing)
- **Draft Badge**: Shows saved draft count (if any)
- **Arrow**: Click anywhere on card to select

### Draft Management
- **Save**: Click "Save Draft" in form
- **View**: See all drafts in valuer profile
- **Edit**: Click "Continue Editing" on draft
- **Delete**: Click "Delete" to remove draft

## 🎯 Common Tasks

### Find a Specific Bank
```
1. Click in search box
2. Type bank name (e.g., "Kotak")
3. Click on the bank card
```

### Filter by Type
```
1. Click "Banks" for banking institutions
2. Click "Finance Companies" for NBFCs
3. Click "Housing Finance" for housing finance companies
4. Click "All Banks" to see everything
```

### Save Work in Progress
```
1. Fill out form fields
2. Click "Save Draft" button
3. Confirmation message appears
4. Return to profile to see draft
```

### Continue Saved Draft
```
1. Go to Valuer Profile
2. Click "Show AU Small Finance Drafts"
3. Find your draft in the list
4. Click "Continue Editing"
5. Form opens with saved data
```

## 🔧 Troubleshooting

### Can't Find a Bank?
- Check spelling in search
- Try filtering by category
- Clear search and browse all

### Draft Not Saving?
- Check internet connection
- Verify you're logged in
- Try refreshing the page

### Draft Count Not Showing?
- Refresh the page
- Check backend is running
- Verify authentication
